Vetest · Web para Centro Veterinario

Sitio web completo para una clínica veterinaria, con sistema de reserva de citas en tiempo real, alta automática en el calendario del centro y avisos por email. Desarrollado como proyecto propio de principio a fin.


Nota: «Vetest» es un nombre y una identidad ficticios, creados con fines de demostración y portfolio.




✨ Características


Diseño responsive, cálido y optimizado para SEO.
Reserva de citas con franjas horarias en tiempo real: las horas ya ocupadas se bloquean para el resto de visitantes.
Alta automática de la cita en el calendario del centro, con aviso el día antes.
Notificación por email a la clínica con los datos de cada solicitud.
El cliente puede guardar su cita en su propio calendario.
Web estática (HTML, CSS y JavaScript, sin frameworks) conectada a servicios en la nube, sin servidor propio.


🛠️ Tecnologías


HTML5, CSS3 y JavaScript (vanilla).
Firebase Realtime Database (estado de franjas ocupadas).
Google Apps Script (creación de eventos en el calendario).
Web3Forms (envío de formularios por email).
